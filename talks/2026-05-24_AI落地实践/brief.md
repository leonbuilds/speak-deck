## 必须出现的点

1. 三个产品案例（clip-shot 极简工具 / landr 全链路 Agent / 企业真实项目）
2. 四种编程范式（Vibe → SPEC → Agentic → 未来 ID Coding）
3. SPEC.md 的核心价值（「不做清单」是最值钱的那行）
4. 开发者角色转变：写代码 → Reviewer / Architect / Commander
5. 结尾行动指引：本周就动手做第一个，给它写一份 SPEC

## 绝对不要出现

- 工具名词轰炸（挑重点讲，不做功能参数对比）
- 「赋能」「抓手」「闭环」等黑话
- 「今天非常荣幸」「首先其次最后」

## 风格

- 同行分享腔：有锋芒、有观点、留勾子
- 说话像视频文字稿里的阿亮：口语感强、夹带真实案例数字、偶尔插「我当时是这么想的」
- 语速 200 字/分钟；页均 500 字（40 分钟 ÷ 15 页）
- 数据呈现口语化：不说「75%」，说「四个里有三个」
