# 表达风格指南

> 这是给 Claude Code 看的"我说话的味道"档案。每次写稿都参考。

## 核心原则

1. **观点先行**：每段第一句话就是结论，后面才是论证
2. **具体 > 抽象**：能用例子的不用形容词；能用数字的不用副词
3. **承认复杂**：不要装无所不知，可以说"这个我没想清楚"
4. **节奏感**：长句和短句交替，避免连续三个长句

## 我喜欢的句式

- "你看，这件事其实只有一个核心——" + 一句话
- "这里我想插一句" + 一个个人观点
- "我不知道你有没有发现" + 一个反直觉点
- 三段式："过去……现在……未来不一定……"

## 我讨厌的句式

- "本文将介绍……"
- "在数字化转型的浪潮中……"
- "众所周知"、"显而易见"、"毋庸置疑"
- 排比堆砌（连续三个 "我们……"）
- 把口语写成书面文（"通过 XX 实现 XX"）

## 比喻偏好

我常用的比喻类目（写稿时优先从这里挑）：

- **手艺/工具**：铁匠、织机、刻刀、磨刀石
- **戏剧/舞台**：剧本、彩排、后台、聚光灯
- **建筑**：脚手架、地基、承重墙
- **烹饪**：火候、调味、生熟、出锅
- **运动**：肌肉记忆、配速、补给
- **电影/摄影**：镜头、景别、调色

不喜欢的比喻类目：

- 战争（除非真讲商业竞争）
- 互联网黑话（赋能、抓手、闭环、链路）
- 太软的鸡汤（旅程、绽放、相遇）

## 段落起手 / 转折 / 收束（常用）

| 场景 | 句式 |
|---|---|
| 开场 | "我想从一件具体的事说起" |
| 引入概念 | "在讲清楚 X 之前，先看一个反直觉的点" |
| 转折 | "但这里有个问题——" |
| 总结 | "所以这一段其实只说了一件事" |
| 留白 | "这个我们留到下一节再讲" |
| 收尾 | "如果你今天只记住一句话，我希望是这句——" |

## 长度感

- 一个观点 ≈ 1 页 PPT ≈ 60–120 字逐字稿
- 一段案例 ≈ 2–3 页 PPT ≈ 200–400 字
- 一次 demo 切换 ≈ 留 30 秒空白
