# Leon's PVI Style（Mode A HTML 视觉档案）

> Personal Visual Identity —— 我的演讲网页默认视觉风格。Claude Code 在 Mode A 渲染 HTML 时按这套来；Mode B 仅供口播稿语气参考，不动原页面视觉。

## 配色（深色基调，可切换浅色）

| 用途 | 色值 | 说明 |
|---|---|---|
| 主背景 | `#0E1116` | 接近纯黑，但带一点蓝灰 |
| 卡片背景 | `#161B22` | 比主背景略亮 |
| 主文字 | `#E6EDF3` | 浅灰白，护眼 |
| 次文字 | `#9AA4B2` | 注释、辅助说明 |
| 强调色 1 | `#4FB6FF` | 蓝，关键词/数字 |
| 强调色 2 | `#FFB454` | 橙，反例/警示/对比 |
| 分隔线 | `#1F242C` | 极弱分隔 |

## 字体

- 中文：`"PingFang SC", "Noto Sans SC", system-ui`
- 英文/数字：`"Inter", system-ui`

| 角色 | 字号 | 字重 | 行高 |
|---|---|---|---|
| H1 | 64px | 700 | 1.2 |
| H2 | 40px | 600 | 1.3 |
| 正文 | 24px | 400 | 1.6 |
| 注释 | 18px | 400 | 1.6 (opacity 0.6) |

## 排版

- 每页留白 ≥ 8%（`padding: 8vh 10vw`）
- 标题**居左**不居中
- 数字、关键词 → 强调色 1
- 反例、警示 → 强调色 2
- 表格简化：**无竖线**、只保留底边线

## 强调方式

- 关键词 → 加粗 + 强调色 1
- 引语 → 左侧 4px 强调色竖条 + 斜体
- 数据 → 大号数字 + 极简注释（注释用次文字色）
- 对比 → 两栏并列，左侧主张、右侧反例（用强调色 2）

## 节奏（影响每页信息量）

- 概念页：1 个 H1 + 1 段正文 + 0 bullet
- 论点页：1 个 H1 + 1 段引子 + 3 bullet（每条不超过 18 字）
- 数据页：1 个 H1 + 1 个超大数字 + 1 行注释
- 案例页：1 个 H1 + 一张图（占 60%）+ 3 行说明
