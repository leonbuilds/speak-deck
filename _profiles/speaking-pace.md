# 语速 / 口头禅档案

> 每次写逐字稿都要参考；同时是 TTS 时调 speed/停顿的依据。

## 基础节奏

- **语速**：约 200 字/分（中文）
- **停顿**：自然句号停 0.5s，段落间停 1.5s，强调前停 0.3s
- **强调**：关键词稍重读、稍慢

## 字数 → 时长换算

| 时长 | 字数 |
|---|---|
| 5 分钟 | ≈ 1000 字 |
| 15 分钟 | ≈ 3000 字 |
| 30 分钟 | ≈ 6000 字 |
| 45 分钟 | ≈ 9000 字 |
| 60 分钟 | ≈ 12000 字 |

## 我常用的衔接词（保留）

- "其实"、"那"、"对吧"、"你看"
- "我们直接看"、"我直接给你"
- "回到刚才那个点"

## 我不用的（写稿时要剔除）

- "首先、其次、最后"
- "众所周知"
- "在开始之前"
- "今天非常荣幸"
- "希望对大家有所帮助"

## 段落起手

- 概念引入：「我们先把……搞清楚」
- 转折：「但是，真正的问题不在这」
- 收束：「所以这一段其实就说了一件事——」

## 数据呈现

- 不直接说 "百分之七十五"，说 "**四个里有三个**"
- 不直接说 "增长 3 倍"，说 "**从一个变成三个**"
- 大数字后立刻给类比："**500 份方案——大概每周一份，做了 10 年**"

## TTS 参数建议（MiniMax）

```json
{
  "speed": 1.0,
  "vol": 1.0,
  "pitch": 0
}
```

如果某页内容信息密度高、需要听众消化 → `speed: 0.95`。
如果是过渡页、引子 → `speed: 1.05`。
